## 🎯 Features

- 🔬 **Hash Identification** - Auto-detect 50+ hash types
- ⚡ **Multi-threaded** - Julia's parallel processing for max speed
- 📚 **Dictionary Attack** - Wordlist-based cracking
- 🔄 **Rule Engine** - Password mutation rules
- 🎲 **Brute Force** - Charset-based generation
- 🌈 **Rainbow Support** - Generate and use rainbow tables

### Supported Hash Types
MD5, SHA1, SHA256, SHA512, bcrypt, NTLM, MySQL, PostgreSQL, and 40+ more

## 🚀 Usage

```bash
# Identify hash type
julia hashwitch.jl identify -h "5f4dcc3b5aa765d61d8327deb882cf99"

# Dictionary attack
julia hashwitch.jl crack -h hash.txt -w rockyou.txt

# Brute force
julia hashwitch.jl crack -h "098f6bcd..." -m md5 --brute -c "?l?l?l?l?d?d"
```
